# Flat White Living — Brief para Claude Design

Paquete de referencia para maquetar la web desde cero en Claude Design. Copy y estructura ya cerrados (ver documento Word); este archivo resume solo lo que necesitas para diseñar.

## Identidad
- **Positioning:** Interior design, with everything taken care of.
- **Subtítulo:** Bespoke interior design and project management for international clients in the Netherlands.
- **Base:** The Hague, Países Bajos.
- **Tono de marca:** calmado, editorial, personal, sofisticado — *nunca* "lujo" explícito.

## Dirección visual (del brief original, sección 13)
- Editorial, calmado, personal, sofisticado — no "luxury" explícito.
- La fotografía de proyecto lidera visualmente; tipografía y layout restringidos, no decorativos.
- Espacio en blanco generoso; composición de imagen fuerte.
- La fundadora debe ser visible: retrato profesional + "About" auténtico como elemento de confianza.
- Navegación principal simple — no meter cada servicio/categoría en el header.
- CTA "Start a Project" persistente o muy visible.
- En páginas de proyecto: equilibrio entre fotografía y narrativa suficiente para comunicar expertise.
- **Mobile-first**: los clientes internacionales suelen descubrir el estudio desde el móvil.
- Evitar fotografía de stock genérica — usar trabajo propio del estudio y entornos reales.

## Placeholders de imagen (pendiente de fotos reales — acordado con la clienta)
Hasta que se suban fotografías propias, usar placeholders neutros (bloques de color / silueta / marca de agua "Foto pendiente"), **no** stock genérico de interiorismo, para no fijar una dirección visual falsa. Slots necesarios:

| Página | Placeholder necesario | Notas |
|---|---|---|
| Home — Hero | 1 imagen ancha (hero) | Foto de proyecto real, cálida, editorial |
| Home — Servicios | 5 imágenes cuadradas/verticales | Una por servicio (Interior Design, Architecture, Project Management, Styling, Property Staging) |
| Home — Selected projects | 3–6 miniaturas | Vinculadas a páginas de proyecto |
| Services (cada subpágina) | 1–2 imágenes por servicio | — |
| For International Clients | 1 imagen de apoyo | Ambiente/estilo de vida, no genérica |
| About | 1 retrato profesional | Elemento de confianza clave — sustituir por foto real en cuanto esté disponible |
| Projects — landing | Grid de 4–6 proyectos mínimo | Cada uno con su propio set de fotos |
| Project page (plantilla) | Hero + galería + antes/después si aplica | Estructura definida en sección 8 del brief |
| Journal | 1 imagen por artículo | — |
| Contact | Opcional: imagen de ambiente | — |

## Estructura de navegación
HOME · PROJECTS · SERVICES · ABOUT · HOW IT WORKS · JOURNAL · START A PROJECT

Submenú Services: Interior Design / Architecture / Project Management / Styling / Property Staging
Submenú Projects: Residential / Apartments / Houses & Villas / Renovations / Hospitality & Commercial

Home · Services (+5 subpáginas) · For International Clients · About · How It Works · Projects (landing + 4–6 proyectos) · Journal (landing) · Contact
